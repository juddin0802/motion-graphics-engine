# 📦 সংরক্ষিত পুরনো ভিডিও (Archived Videos)

এই ফোল্ডারে আপনার তৈরি করা আগের ভিডিওগুলোর স্ক্রিপ্ট, অডিও এবং সিনের ফাইলগুলো নিরাপদে সংরক্ষিত থাকে।

### এই ফোল্ডারে ফাইল কখন আসবে?
আপনি যখন নতুন ভিডিও তৈরির জন্য টার্মিনালে এই কমান্ডটি চালাবেন:
```bash
npm run new-video
```
তখন আপনার আগের ভিডিওর সমস্ত কাজ তারিখ ও সময় অনুযায়ী এই ফোল্ডারের ভেতর একটি নতুন ফোল্ডার তৈরি করে ব্যাকআপ হিসেবে সংরক্ষণ করা হবে (যেমন: `archived-videos/2026-10-20_client_video/`)।

### জরুরি বিষয়:
1. এই ফোল্ডারের ফাইলগুলো আপনার নতুন ভিডিও তৈরিতে কোনো বাধা বা সমস্যা তৈরি করবে না।
2. যদি অনেকদিন পর আপনার কম্পিউটারের স্টোরেজ খালি করার প্রয়োজন হয়, তবে আপনি যেকোনো সময় এই ফোল্ডারের ভেতর থাকা অপ্রয়োজনীয় পুরনো ব্যাকআপ ফোল্ডারগুলো ডিলিট করে দিতে পারেন।
