# 🎬 Remotion Reusable Motion Graphics Studio
> যেকোনো SRT ও ভয়েসওভার থেকে প্রফেশনাল মোশন গ্রাফিক্স ভিডিও তৈরির রিইউজেবল ইঞ্জিন

👉 **বিস্তারিত ব্যবহার নির্দেশিকা দেখতে পড়ুন: [USER-GUIDE.md](./USER-GUIDE.md)** (নতুন ভিডিও তৈরি, ফাইল আপলোড, ডিলিট ও ডাউনলোড গাইড)

এই প্রজেক্টটি এমনভাবে তৈরি করা হয়েছে যাতে **কোডিং না জেনেও** যেকোনো বিগিনার শুধুমাত্র তার স্ক্রিপ্ট (SRT) ও ভয়েস অডিও ড্রপ করেই সম্পূর্ণ প্রফেশনাল মোশন গ্রাফিক্স ভিডিও তৈরি করতে পারেন।

---

## 🚀 নতুন ভিডিও বানানোর ৩টি সহজ ধাপ

### ধাপ ১: ফাইল আপলোড করা
আপনার ভিডিওর ফাইলগুলো শুধু **`input-content/`** ফোল্ডারে রাখবেন:

| ফাইল | কোথায় রাখবেন? | কেন প্রয়োজন? |
| :--- | :--- | :--- |
| **`voiceover.srt`** | `input-content/` | **বাধ্যতামূলক**। ভিডিওর টাইমিং ও লেখার মূল স্ক্রিপ্ট। |
| **`voiceover.mp3`** | `input-content/` | *ঐচ্ছিক*। অডিও ভয়েস ফাইল (mp3, wav বা m4a)। |
| **লোগো / ছবি** | `input-content/assets/` | *ঐচ্ছিক*। কোনো টুল, কোম্পানি বা ক্লায়েন্টের লোগো/স্ক্রিনশট। |
| **`brief.md`** | `input-content/` | *ঐচ্ছিক*। ভিডিওর কোনো বিশেষ রং, সাইজ বা নির্দেশনার নোট। |

---

### ধাপ ২: ফাইল ডিলিট বা রিসেট করা
**আপনাকে কোনো ফাইল ম্যানুয়ালি ডিলিট করতে হবে না!**  
পুরনো ভিডিও শেষ হলে নতুন ভিডিও শুরু করার জন্য টার্মিনালে শুধু এই একটি কমান্ড দিন:
```bash
npm run new-video
```
*(আপনার দেওয়া আগের সব সিন ও ফাইল স্বয়ংক্রিয়ভাবে `archived-videos/` ফোল্ডারে ব্যাকআপ হয়ে যাবে, ফলে কোনো কাজ নষ্ট হওয়ার ভয় নেই।)*

---

### ধাপ ৩: কমান্ড চালানো

#### ক. ফাইল প্রস্তুত করা (Asset Preparation):
ফাইলগুলো `input-content/` ফোল্ডারে রাখার পর টার্মিনালে চালান:
```bash
npm run prepare-video
```
*(এটি SRT পার্স করবে, অডিও লিঙ্ক করবে এবং তাৎক্ষণিক প্রিভিউয়ের জন্য রেডি করবে।)*

#### খ. লাইভ প্রিভিউ দেখা (Remotion Studio):
ভিডিওটি কেমন দেখাচ্ছে তা ব্রাউজারে লাইভ দেখার জন্য চালান:
```bash
npm run studio
```
*(আপনার ব্রাউজারে একটি উইন্ডো খুলবে যেখানে ফ্রেম বাই ফ্রেম ভিডিও দেখতে ও শুনতে পারবেন।)*

#### গ. সম্পূর্ণ MP4 ভিডিও রেন্ডার করা:
ভিডিও পুরোপুরি পছন্দ হলে নিজের কম্পিউটারে ফাইনাল MP4 ভিডিও ফাইল তৈরি করতে চালান:
```bash
npm run render-video
```
*(রেন্ডার হওয়া ভিডিওটি `generated-videos/video.mp4` ফাইলে সেভ হবে।)*

## 🤖 AI এজেন্ট (Antigravity / Claude / Codex) দিয়ে ভিডিও বানানোর নিয়ম

আপনি নিজে কোনো কোড লিখতে না চাইলে সরাসরি আপনার AI এজেন্টকে চ্যাটে বলুন:

> *"আমি `input-content/` ফোল্ডারে নতুন SRT ও অডিও দিয়েছি। প্রজেক্টের নিয়ম ও instructions ফলো করে নতুন ভিডিওর কাস্টম সিন বানিয়ে দাও।"*

**এজেন্ট নিজে থেকেই নিচের কাজগুলো ধাপে ধাপে করবে:**
1. পুরো SRT স্ক্রিপ্ট বিশ্লেষণ করবে।
2. আপনাকে **৪–৬টি সুন্দর কালার স্কিম** প্রস্তাব করবে এবং জানতে চাইবে আপনার কোনটা পছন্দ।
3. আপনার পছন্দের রঙে `src/video/scenes/` ফোল্ডারে আকর্ষণীয় ভিজ্যুয়াল সিন কোড লিখবে।
4. কোনো ভুল বা ওভারল্যাপ আছে কি না তা স্টিল ফ্রেম রেন্ডার করে নিজে নিজেই যাচাই করবে।
5. আপনাকে লাইভ প্রিভিউ দেখার জন্য প্রস্তুত করে দেবে।

## ⚙️ সহজ কাস্টমাইজেশন (বিগিনারদের জন্য)

### ১. ভিডিওর সাইজ বা অনুপাত পরিবর্তন (YouTube নাকি Reels/Shorts?)
ফাইল: **[`src/video-config.ts`](./src/video-config.ts)**  
- YouTube / Facebook লং ভিডিও (1920 × 1080):  
  `export const VIDEO_FORMAT = "landscape";`
- Reels / Shorts / TikTok খাড়া ভিডিও (1080 × 1920):  
  `export const VIDEO_FORMAT = "reel";`
- Instagram / LinkedIn স্কয়ার ভিডিও (1080 × 1080):  
  `export const VIDEO_FORMAT = "square";`

### ২. কালার স্কিম বা ব্র্যান্ডের রং পরিবর্তন
ফাইল: **[`src/video-theme.ts`](./src/video-theme.ts)**  
ফাইলটির উপরে `BASE_PALETTE`-এ আপনার পছন্দের HEX কোড বসিয়ে দিন:
```ts
export const BASE_PALETTE = {
  bg: "#0B1020",      // ব্যাকগ্রাউন্ডের রং
  primary: "#6C7CFF", // হিরো/প্রধান রং
  accent: "#2DE2C5",  // হাইলাইট ও অ্যাকসেন্ট রং
  text: "#F2F5FF",    // লেখার প্রধান রং
  ...
};
```

## 💡 জরুরি কিছু প্রশ্ন ও উত্তর (FAQ)

**প্রশ্ন: আমি কি বাংলা টেক্সট ব্যবহার করতে পারব?**  
**উত্তর:** হ্যাঁ! এই প্রজেক্টে Hind Siliguri বাংলা ফন্ট অফলাইনে এম্বেড করা আছে। বাংলা যুক্তাক্ষর ভাঙবে না।

**প্রশ্ন: সাউন্ড ইফেক্ট কি সাথে সাথে পাওয়া যাবে?**  
**উত্তর:** হ্যাঁ, `public/sound-effects/` ফোল্ডারে Whoosh, Pop, Click, Swipe, Chime সাউন্ড বিল্ট-ইন দেওয়া আছে। আপনি চাইলে `src/video-config.ts`-এ `SFX_SOUND_ENABLED = false` করে বন্ধও করতে পারেন।

**প্রশ্ন: লোগো কীভাবে সিনে দেখাব?**  
**উত্তর:** লোগোটি `input-content/assets/logo.png` নামে রাখুন এবং `npm run prepare-video` চালান। এরপর কোডে লিখুন:
```tsx
import { getUserAssetUrl, hasUserAsset } from "../lib/user-assets-manager";
import { Img } from "remotion";

{hasUserAsset("logo.png") && <Img src={getUserAssetUrl("logo.png")} />}
```
