All AI coding assistants (Google Antigravity, Claude Code, OpenAI Codex, GitHub Copilot) working in this repository **MUST** strictly follow BOTH of the following documents before writing or modifying any code:

2. **[.agents/skills/remotion-motion-graphics/SKILL.md](./.agents/skills/remotion-motion-graphics/SKILL.md)** (Remotion Motion Graphics Skill): 5-layer compositing, spring physics, animation timing, layout patterns, and motion graphic design rules.

## 1. Project Architecture & Philosophy

This project is a **universal, reusable Remotion Motion Graphics engine**.
Users do not write code. Users only provide:
- `input-content/voiceover.srt` (Mandatory subtitle cues)
- `input-content/voiceover.mp3` or `.wav` (Optional voiceover audio)
- `input-content/assets/` (Optional client logos, screenshots, images)
- `input-content/brief.md` (Optional video topic, color preference, instructions)

### Engine vs. Video Files
- **Engine Files (DO NOT MODIFY unless fixing core bugs):**
  - `src/video-root.tsx` & `src/index.ts` (Remotion root registration)
  - `src/video-main-composition.tsx` (5-layer compositor: Mesh -> Scenes -> Grade -> Vignette)
  - `src/video-config.ts` (Aspect ratio: landscape/reel/square, FPS, audio flags)
  - `src/video-theme.ts` (Design tokens, spring physics, easings, color palette)
  - `src/srt-timing.ts` (SRT-driven timing engine: `getCueStartTime`, `getWordTimeInCue`, etc.)
  - `src/voiceover-audio-player.tsx` (Voiceover audio component)
  - `src/lib/*` (Reusable UI components, icons, scene builders, auto-draft engine)
  - `src/generated/*` (Auto-generated by `npm run prepare-video`)

- **Video-Specific Files (THIS IS WHAT YOU CREATE/MODIFY FOR EACH VIDEO):**
  - `src/video/scene-plan.ts`: Registers the scenes using `buildVideoScenes([...])`.
  - `src/video/scenes/*.tsx`: The custom visual scenes crafted for the current script.
  - `src/video-theme.ts` (`BASE_PALETTE`): The 4-6 hex colors chosen for the brand/topic.

## 2. Standard Workflow for Making a Video

Whenever the user asks you to create or update a video for the current project:

### Step 0: Prompt Attachment & Auto-Archive Detection (ZERO-MANUAL WORKFLOW)
Users create videos directly from the AI chat interface (Antigravity IDE / VS Code) using prompt attachments or natural language commands:

1. **Explicit Archive Command:**
   - If the user says *"আগের ভিডিও আর্কাইভ করো"*, *"আর্কাইভে মুভ করো"*, or *"আর্কাইভ করে দাও"*, immediately run:
     `node scripts/archive-old-video.mjs` (or `npm run archive-old-video`)
     and inform the user in Bengali that the previous video is safely archived in `archived-videos/`.

2. **Auto-Archive on New Video Request:**
   - Whenever the user provides/attaches new content or asks for a new video, **CHECK FIRST** if `src/video/scenes/` contains existing custom scenes or `input-content/voiceover.srt` has a previous video.
   - If previous work exists, **AUTOMATICALLY RUN** `node scripts/archive-old-video.mjs` to archive the old project into `archived-videos/` before placing new files!

3. **Auto-Save Attached Content from Chat Prompt:**
   - When the user attaches files to the chat prompt (via `Media` / `+` attachment) or provides raw text in the prompt:
     - Save/move attached `.srt` file (or pasted subtitle text) to `input-content/voiceover.srt`.
     - Save/move attached audio file (`.mp3` or `.wav`) to `input-content/voiceover.mp3`.
     - Save attached images or logos into `input-content/assets/`.
     - Save any user guidelines, topic description, or color wishes to `input-content/brief.md`.

4. **Auto-Run Preparation:**
   - Run `npm run prepare-new-video` automatically in the terminal so `src/generated/cues.ts` and `src/generated/assets.ts` are immediately generated.

### Step 1: Analyze Script & Assets
1. Inspect the parsed cues in `src/generated/cues.ts` and brief in `input-content/brief.md`.
2. Understand the script content, tone, key tools, metrics, and duration.

### Step 2: The Color Scheme Question (The ONLY Question)
Follow Section 2, Step 2 of `USER-TO-AGENT-INSTRUCTIONS.md`:
- Summarize the video topic in 1-2 lines in Bengali.
- Propose 4–6 cohesive color schemes (Hex codes for Background, Hero, Accent, Text).
- Recommend 1–2 schemes with rationale.
- End with this exact sentence:
  > “কোনটা নেবেন? নম্বর বলুন বা নিজের রং জানান।”
- *Exception:* If the user already specified colors in the prompt or `input/brief.md`, do not ask; proceed immediately with their chosen colors.

### Step 3: Design & Code the Custom Scenes
Once colors are determined:
1. Update `BASE_PALETTE` in `src/video-theme.ts` with the selected colors.
2. If the user requested a format (e.g. "রিল" / "Shorts"), set `VIDEO_FORMAT = "reel"` in `src/video-config.ts`.
3. Create distinct visual scenes in `src/video/scenes/` (e.g., `HookScene.tsx`, `FeatureOverviewScene.tsx`, `CallToActionScene.tsx`):
   - Choose styles from Section 3 of `USER-TO-AGENT-INSTRUCTIONS.md` (Glossy UI, Bento Grid, 3D Carousel, Process Timeline, etc.).
   - Vary layouts across scenes (never repeat the exact layout consecutively).
   - Use `VectorIcon` from `src/lib/vector-icons.tsx`. **NEVER USE RAW EMOJI AS ICONS**.
   - Use `WordByWordText` from `src/lib/motion-ui-components.tsx` for text reveals.
   - For user logos/images, check `hasUserAsset(name)` and load via `getUserAssetUrl(name)` from `src/lib/user-assets-manager.ts`.
4. Register the scenes in `src/video/scene-plan.ts` using `buildVideoScenes`.

### Step 4: Verification
1. Run `npm run typecheck` to ensure 0 TypeScript errors.
2. Render still frames at key moments:
   `npx remotion still src/index.ts Main generated-videos/check_frame.png --frame 90 --overwrite`
3. Inspect for layout overlap, clipped Bengali text, or color contrast issues.

### Step 5: Deliver According to Output Mode
- **Preview Mode (Default):**
  Give the standard 3 commands in Bengali with explanations as detailed in Section 10.1 of `USER-TO-AGENT-INSTRUCTIONS.md`:
  1. `npm install`
  2. `npm run studio`
  3. `npx remotion render src/index.ts Main generated-videos/video.mp4`
  End with:
  > “কোনো সিন বদলাতে চান? আর চ্যাটেই ভিডিওটা MP4 ফরম্যাটে রেন্ডার করে দেব কি? চাইলে 'রেন্ডার করো' বলুন।”
- **Render Mode:**
  If the user says "রেন্ডার করো", execute:
  `npx remotion render src/index.ts Main generated-videos/video.mp4`
  and report the completed MP4.

## 3. Non-Negotiable Rules

0. **Mandatory Skill & Instruction Execution:**
   - Any agent working on this repository MUST activate and apply `.agents/skills/remotion-motion-graphics/SKILL.md` and `USER-TO-AGENT-INSTRUCTIONS.md`.
   - Never generate static, plain, or linear animations. Adhere to spring physics, 5-layer compositing, and typography rules.
1. **SRT is the Single Source of Truth for Timing:**
   - NEVER write hardcoded numbers for seconds.
   - ALWAYS use `getCueStartTime(n)`, `getCueEndTime(n)`, `getWordTimeInCue(n, "phrase")`, or `evenlyDistributeInCue(n, count)`.
2. **Bengali Typography Integrity:**
   - NEVER split Bengali text by characters. Only split by spaces (`" "`).
   - Keep `letterSpacing: 0` for all Bengali text.
   - Ensure the display font is `'Hind Siliguri', sans-serif`.
3. **No Raw Emojis:**
   - Emojis render in platform colors and break palette consistency. Use `VectorIcon` or draw SVG paths with theme colors.
4. **No Flat Backgrounds:**
   - The 5-layer stack in `src/video-main-composition.tsx` must be preserved.
5. **No Linear Motion:**
   - Always use `theme.spring.snappy`, `theme.spring.smooth`, `theme.spring.bouncy`, or `theme.ease.out` / `theme.ease.inOut`.
6. **User Image Deconstruction Protocol (Mandatory When User Uploads/Provides Images):**
   - **Never display the user's uploaded image as a static flat whole image or ignore it.**
   - If the user provides an image (workflow, screenshot, dashboard, diagram, architecture chart) in `input-content/assets/` or prompt:
     - **Break down the image into its component blocks/sections/nodes** (e.g. Webhook, Filter, AI Agent, DB Memory, Switching, Output nodes).
     - **Animate those blocks individually as rich motion graphics** (interactive glass cards, glowing nodes, animated wires, pulsing data packets, word reveals) **synchronized with the voiceover cues**.
   - **If no image is provided**, use bespoke vector iconography, kinetic typography, and theme-based motion graphics layouts.
7. **Visual-First Protocol (Zero Text Slides):**
   - The voiceover audio does the talking; the screen is NOT a PowerPoint presentation.
   - Never fill the screen with large centered paragraph text.
   - 90–95% of the screen must be dedicated to functional visual motion graphics and connected diagrams:
     - **Content Calendar**: Full visual Google Sheets UI table with rows, statuses, and live extraction wire.
     - **Social Media**: Central automation trigger node branching with glowing electrical wires to Facebook, Instagram, LinkedIn, X, and Threads.
     - **Workflow / Automation**: Interactive n8n node pipelines with pulsing data packets.
     - **Approval**: Interactive glass review card with toggle switch (Pending -> Approved) and human check.
     - **Payment**: Connected payment hub with authentic bKash origami bird, Nagad, Stripe, and Cards.
   - Spoken subtitle cues must remain in a minimal, sleek floating glass caption pill at the bottom.
